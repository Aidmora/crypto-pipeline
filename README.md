# Real-Time Crypto Pipeline

Pipeline de procesamiento de datos en tiempo real para precios de criptomonedas.

## Objetivo

Construir un pipeline que ingiera precios de criptomonedas desde la API pública de CoinGecko, los procese con Apache Spark Structured Streaming, los persista en formato Parquet y los visualice en un dashboard interactivo.

## Stack tecnológico

- **Apache Kafka** — Bus de eventos en tiempo real
- **Apache Spark Streaming** — Procesamiento distribuido
- **Docker Compose** — Orquestación de servicios
- **Python 3.11** — Producer y dashboard
- **Streamlit** — Visualización (próximamente)
